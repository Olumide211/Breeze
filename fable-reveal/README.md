# Fable 5.5 logo reveal

A 10-second (300 frames at 30fps), 1080×1920 logo film in a single file: `index.html`. Open it in Chrome.

| Key | Action |
| --- | --- |
| Space | Play / pause |
| ← → | Step one frame |
| R | Restart |
| H | Hide / show the control bar |
| `?t=4.5` | Open paused at 4.5 s (add `&play` to start playing from there) |

**Rendered video:** `fable-5.5-reveal.mp4` is the film as an H.264 MP4: 1080×1920, 30fps, 300 frames, exactly 10.0 s. It was rendered frame by frame offline.

**Recording:** "● Rec" captures a 1080×1920 webm at 30fps and 24 Mbps, then downloads it. Keep the tab visible while it records.

**Sound:** the sound cue sheet is the HTML comment at the top of `index.html`. Exact keystroke frames are printed to the console.

**Assets:** `claude-spark-traced.svg` is the spark vector the film uses. It was traced from the supplied PNG because no SVG was attached.
